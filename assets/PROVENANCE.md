# Fren Pet cat asset provenance

The contract embeds `cat.png` as a data URI. It does not fetch art from a server.
`cat.svg` is a readable vector equivalent; neither requires an external font,
image or stylesheet. All three colors and the pixel arrangement are preserved.

## Sources and selection

Retrieved on 2026-10-03:

- The requested reference NFT is [Fren Pet #15845 on OpenSea](https://opensea.io/item/base/0x5b51cf49cb48617084ef35e7c7d7a21914769ff1/15845).
- Its page's `imageUrl` identifies [the reference SVG](https://raw2.seadn.io/base/0x5b51cf49cb48617084ef35e7c7d7a21914769ff1/c8e639a9a757eb0a290ade1548fee8/78c8e639a9a757eb0a290ade1548fee8.svg), saved unchanged as `reference-15845.svg` (7,088 bytes).
- The official [branding page](https://docs.frenpet.xyz/branding) links its [asset archive](https://docs.frenpet.xyz/assets/files/assets-d2b99dc9a0a77f453a603edc0e94b29f.zip). The cat is visually the upper-right sprite in `Pack/Character Sheet/Character and Color.png`. The seven individual `Pack/Monster/` PNGs are different characters and were not substituted for the cat.
- The user also supplied the [brand guidelines PDF](https://docs.frenpet.xyz/assets/files/frenpet-brand-guidelines-e3650af0953ee0ce0bd1d08e9d4e4a60.pdf).

The implementation relies on the assignment's explicit statement that Fren Pet
permits reuse of its art without copyright restrictions or royalties. The
currently accessible branding page distributes the art but does **not** itself
state a CC0 dedication or royalty waiver; it has a `Copyright © 2024 FREN PET`
footer. No additional license or ownership claim is invented here.

## Conversion and embedding

The reference uses rectangular vector paths on a 23 × 21 pixel grid, padded to
a 500 × 500 canvas. `compact_cat.py` recovers that grid from the reference's
rounded decimal coordinates, removes empty canvas padding and redundant
painted paths, and preserves the original draw order. It is a deterministic
conversion of supplied art, with no generated or replacement artwork. This
snaps subpixel decimal-rounding discrepancies in the source to the intended
pixel grid; it is not claimed to preserve those insignificant vector seams.
The colors are `#ACBFAB`, `#000000`, and `#D5FBE6`, plus transparency.

Run `python3 assets/compact_cat.py` to reproduce the assets offline. Only the
Python standard library is needed; Foundry does not run or depend on this
conversion script. The already-generated bytes are included in the project.

- `cat.png`: 206 bytes, transparent indexed PNG, 23 × 21 pixels.
- `cat.base64.txt`: 276 base64 characters followed by one newline.
- Complete `data:image/png;base64,...` URI: 298 bytes.
- `cat.svg`: 1,446 bytes, a readable standalone vector equivalent.

Render at the 23:21 aspect ratio and use `image-rendering:pixelated` for crisp
pixel art. SVG `<image>` definitions may be reused with `<use>` so a layout
stores the embedded image payload only once.
